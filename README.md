# 🕒 Realtime Digital Clock

**MeraSamay** is a sleek and responsive digital clock application built using **HTML, CSS, and JavaScript**. It displays the current time in real time with a clean interface, providing users with an accurate and visually appealing way to keep track of time.

## ✨ Features

* ⏰ Real-time digital clock
* 🔄 Automatic time updates every second
* 🎨 Clean and responsive user interface
* ⚡ Lightweight and fast
* 📱 Works seamlessly across devices
* 🛠️ Built with vanilla JavaScript

## 🔄 How It Works

1. 🚀 The application starts automatically on page load.
2. 🕒 The current system time is retrieved.
3. 🔄 The clock updates every second in real time.
4. ⏱️ Users can continuously monitor the current time.
